# Testing and feedback

Current build: Windows x64 VST3 0.4.1, installer R17. No native Mac build.

Use copies of test projects. Save work and close audio hosts before any installation you choose to perform. The installer is unsigned; do not disable security protections or bypass warnings. Keep listening levels moderate.

Report in Issues:
- DAW and exact version, Windows version, sample rate and buffer size.
- Plugin version and trigger mode (SYNC, MIDI or AUDIO).
- Reproduction steps, expected behavior and observed behavior.
- Relevant routing, parameter values and whether it repeats in a clean test project.
- CPU, latency, clicks, dropouts, automation, recall or UI scaling observations.

Remove private information from screenshots/logs. Share audio only if you have permission. Honest negative feedback is as useful as a successful compatibility report.
