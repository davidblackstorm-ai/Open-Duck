# Known limitations

- Windows x64 VST3 is the current platform. No Mac build; macOS porting and testing are requested. Linux is unverified.
- Native Ableton validation is incomplete. The partial native report concerns an earlier R15 payload, not proof of complete R16/R17 validation.
- R17 report describes 18 preflight checks and 8 isolated setup QA checks. It preserves R16 audio checks (435), Steinberg 47/0 and pluginval strictness 10 by payload identity. These reports were not re-run for publication and do not establish universal compatibility or freedom from bugs.
- The installer is unsigned; its production installation was not run for this publication.
- The full developer source snapshot is supplied in the repository and as a release archive. It preserves the project structure; no new compilation has been run for publication.
- Assets and original dependency notices are included in the source archive. Preserve attribution and applicable licenses when modifying or redistributing.
