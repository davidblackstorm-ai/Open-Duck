# Contributing

Thank you for helping Open Duck. This is a voluntary, unpaid project.

Start an Issue describing the bug, proposed feature, UI design or macOS work you want to tackle. Include a small scope and how you will verify it. For code work, download the complete source archive from Releases; it includes the original project structure and bundled JUCE. Review the technical docs and preserve parameter IDs, plugin identity and backwards-compatible state unless a reviewed change explicitly requires migration.

Submit a focused patch or an appropriate pull request with rationale and test results. Never include passwords, API keys, proprietary SDK binaries, private projects or third-party assets without permission. Preserve license notices and contributor attribution. Only contribute material you have the right to publish under compatible project terms.

Needed: C++/JUCE review and refactoring, real-time DSP and performance, bug reproduction, native DAW testing, usability/accessibility, original graphics, documentation and a macOS port. Do not claim a port or test is complete without evidence. Discuss substantial rewrites before investing effort.
